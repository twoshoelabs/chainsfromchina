# Outlet photos for the "Who they are" tab

Drop a representative photo of one of each chain's outlets **in China** here, named to match the
`photo` field in `manual/companies.json` (e.g. `heytea.jpg`, `mixue.jpg`).

Only use images you have the right to use — licensed stock, an official brand press image with
permission, or your own photograph. Do NOT save a copyrighted storefront photo pulled from the web.
Until a file exists, the tab shows a neutral "photo to come" placeholder. Set `photo_credit` in
companies.json to show a credit line beneath the image.
